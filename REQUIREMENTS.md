# Project Requirements

## Technical Requirements
- use SQL for data loading, cleaning, filtering, and metric generation
- use Python for comparison logic, scoring, and output generation
- use Git and GitHub for version control
- maintain reproducible file structure and naming
- keep raw data separate from processed data

## Project Constraints
- no internal EA data
- no synthetic gameplay telemetry
- no dashboard requirement
- no unnecessary modeling complexity
- no mixing multiple seasons into one permanent team identity

## Data Requirements
- 2024 season used for team profiles
- 2022 to 2024 seasons used for league baselines
- use NFL play-by-play data as the main source
- keep raw source files unchanged after download

## Workflow Requirements
- update documentation as scope changes
- commit work in small, logical increments
- preserve prior code unless intentionally refactoring
- track important scope changes in DECISION_LOG.md
- track progress in TASK_TRACKER.md

## Quality Standards
- code should be readable
- file names should stay consistent
- outputs should be explainable
- metrics should be clearly defined
- recommendations should be framed as benchmarks, not unsupported claims
